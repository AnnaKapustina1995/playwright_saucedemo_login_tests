## SauceDemo UI Tests (Playwright)

Проект с автотестами для сайта https://www.saucedemo.com/  
Тесты покрывают авторизацию, работу с корзиной, а также процесс оформления заказа (в разработке).

## Структура проекта

- `pages/` — Page Object классы
  - `base_page.py` — базовая страница с общими методами и базовым URL
  - `login_page.py` — Page Object страницы логина SauceDemo
  - `inventory_page.py` — Page Object страницы со списком товаров
  - `cart_page.py` — Page Object страницы корзины
  - `checkout_page.py` — Page Object страницы оформления заказа (ввод данных)
  - `checkout_complete_page.py` — Page Object страницы успешного оформления заказа
- `tests/` — автотесты
  - `test_login.py` — тесты авторизации
  - `test_cart.py` — тест корзины (добавление/удаление и бейдж)
  - `test_checkout.py` — тест полного checkout flow до успешной покупки
- `conftest.py` — pytest-фикстуры
- `pytest.ini` — настройки pytest
- `requirements.txt` — зависимости проекта
- `README.md` — описание проекта

## Покрытые тест-кейсы

- Авторизация с корректными данными  
- Авторизация с неверным паролем  
- Авторизация с пустыми полями
- Проверка добавления нескольких товаров в корзину (бейдж корзины и содержимое корзины) 
- Удаление товара из корзины с проверкой бейджа  
- Полный процесс оформления заказа до успешного завершения


## Примечание
Проект разделён на ветки:
  - `main` — актуальная версия проекта (тесты логина и корзины)
  - `feature/cart-tests` — ветка для тестов корзины (вмержена в `main`)
  - `feature/checkout-flow` — ветка для теста оформления заказа
